세 실내 판단 레이어

FALL 낙상

micro-Doppler 스펙트로그램 → CNN (주경로 확정) + Range-Angle 맵 규칙(폴백). v3: BGT60TR13C는 조밀 포인트클라우드 불가(각분해능 ~50°) → 높이규칙 폐기.

{ fall, confidence, 유형 }
VITALS 생명징후

정지 시 흉부 미세변위 → 호흡(0.1–0.5Hz)·심박(0.8–2.5Hz). 움직임 중 "측정불가" 정직 표기.

{ resp_bpm, heart_bpm, 신뢰구간 }
ISOLATION 고독사

사람-상태를 시간축으로. 재실+무동작 N시간→주의→무생체→위험→자동신고. 외출=정상.

{ status, 무동작시간, 마지막생체 }

Gazebo 시뮬레이션

난점: Gazebo엔 mmWave FMCW(micro-Doppler) 네이티브 센서가 없다. 해법: Gazebo는 시나리오의 물리·지상진실만 제공하고, 커스텀 'sim 레이더' 플러그인이 실제 파이프라인과 동일 메시지를 합성 → 탐지 스택은 sim/real 무관.

원룸 SDF 월드 ── 벽·가구 + 충전 스테이션 + 행복이 로봇(URDF)
             └─ Human Actor(스켈레톤): 걷기·앉기·눕기·낙상(앞/뒤/옆)·장시간 무동작
                    │ 링크 pose/velocity (ground truth)
                    ▼
           [커스텀 sim-radar 플러그인]
              경로1(간단): 사람 위치·몸통속도·재실·미세움직임 → '사람 상태' 토픽
              경로2(고급): 신체부위=점산란체 → 도플러 합성 → micro-Doppler → 실제 CNN
              + 도메인 랜덤화(노이즈·클러터·체형)로 sim→real 갭 완화
# 히어로 데모 완전 시뮬: 도킹→전환→낙상→sim레이더→CNN→웹경보 (하드웨어 없이 end-to-end)
