# 행복이 — 블루 & 화이트 디자인 스펙 (EV-inspired)

> Nickelfox "Electric Car App"의 고퀄 패턴(원형 게이지·데이터 카드·지도·굵은 숫자·부드러운 카드)을 **블루 & 화이트**로 리컬러해 흡수한다.
> 보호자 앱 = 풀 EV스타일 / 어르신 키오스크 = 핵심 패턴만 크고 단순하게.
> 승인 목업: `docs/디자인목업_블루화이트.html` · 작성 2026-07-25

---

## 0. 확정 사항 (브레인스토밍)

| 항목 | 결정 |
|---|---|
| 레퍼런스 | Electric Car App (다크+네온그린) → **블루&화이트로 리컬러**, 패턴만 차용 |
| 적용 대상 | **둘 다, 오디언스별 조정** — 보호자=풀, 키오스크=핵심만 크게 |
| 보호자 홈 히어로 | **종합 안심 상태 링** (EV 충전 게이지의 케어 버전) |
| 플랫폼 | 모바일 우선 (보호자), 키오스크는 태블릿급 |
| 접근성 원칙 | 키오스크에서 블루는 **큰 구조·액센트로만**, 본문 텍스트는 **딥 네이비**(최대 명암) |

## 1. 디자인 토큰 (단일 진실원)

`web/src/theme.css` 에 CSS 변수로 정의하고 모든 컴포넌트가 참조한다.

```css
--ground:#F4F7FE;   /* 옅은 블루-화이트 배경 */
--card:#FFFFFF;
--ink:#0F1B33;      /* 딥 네이비 본문 (고대비) */
--muted:#5B6B87;  --faint:#8A97B2;  --line:#E4EAF5;
--blue:#2E6BF6;  --blue-deep:#1B4DB3;  --blue-soft:#EAF1FF;
--grad-hero:linear-gradient(135deg,#1E5BE6,#5B9BFF);  /* 원형 게이지 */
--good:#1FA97A;  --good-soft:#E3F5EE;   /* 안심 */
--danger:#E5484D;  --danger-soft:#FCE9E9; /* 낙상 */
--amber:#E8A23D;
--shadow-sm:0 8px 22px -12px rgba(24,54,120,.28);
--radius:20px; --radius-lg:26px;
--font:'Pretendard','Apple SD Gothic Neo','Malgun Gothic',system-ui,sans-serif;
```

**타이포**: 보호자 — 히어로 게이지 라벨 30px/800, 카드 값 30px, 라벨 13px, 본문 14px. 키오스크 — 상태 38px, 타일 라벨 23px, 값 34px. 숫자는 `tabular-nums`.

## 2. 공통 컴포넌트 (재사용)

| 컴포넌트 | 설명 | 사용처 |
|---|---|---|
| `RadialGauge` | SVG 원형 게이지. props: `value`(0–1), `gradient`, `size`, `track`; 가운데 슬롯(children) | 안심 링, 키오스크 상태 링, 심박 미니 링 |
| `StatCard` | 아이콘칩 + 라벨 + 값(or children) 카드 | 심박·활동·수면 |
| `Sparkbars` | 막대 미니 차트 | 활동량 |
| `IconChip` | 라운드 사각 아이콘 배경(soft blue) | 카드·타일 |
| `Icon` | lucide-react 래퍼 | 전역 |

**아이콘**: lucide-react (이모지 금지). shield-check·heart-pulse·activity·phone·siren·triangle-alert·bell·home·user·settings·wifi·person-standing.
**차트**: 트렌드는 Recharts(또는 uPlot). 고빈도 실시간은 Canvas.

## 3. 보호자 앱 (모바일, `/dashboard`)

신규 화면. 모바일 우선(≤430px 폭 기준), 하단 탭 내비.

### 3.1 홈 (탭: 홈)
- **앱바**: "안녕하세요 / 어머니 상태예요" + 알림 벨(미확인 dot)
- **히어로 카드** — `RadialGauge`(블루 그라데이션, 안심도) 가운데 초록 체크칩 + "안심" + "오늘도 평온해요". 아래 pill: `재실 중 · N분 전 활동 · 이상 없음`
  - 안심도 산출: 재실 여부 + 최근 활동 시각 + 활성 경보 없음 → 상태(안심/주의/위험). 위험 시 링·문구 색 전환(danger).
- **미니 카드 2열**: 심박(`72 회/분`, mini `RadialGauge`) · 활동량(`Sparkbars`)
- **집 지도 카드**: 간이 평면도(SVG) + 현재 방 하이라이트 + 위치 점 + `실내/실외 모드` 배지
- **최근 소식**: CareEvent 스트림을 시간순 리스트(도킹·기상·산책·낙상 등), 색 dot(일반 blue / good green / danger red)
- **하단 탭**: 홈 · 활동 · 알림 · 설정

### 3.2 나머지 탭(스켈레톤 범위 밖, 후속)
- 활동: 활동/수면 트렌드 차트 · 보행속도(돌봄진단)
- 알림: 경보 이력 · 확인 처리
- 설정: 보호자·기기 설정

### 3.3 데이터 소스
기존 WS 게이트웨이(`mode`, `CareEvent`, `heartBpm`) 재사용. 안심 상태·활동량·소식은 이벤트/상태 스트림에서 파생. 스켈레톤 단계에서 활동/수면 등 미제공 값은 시뮬 데이터로 채우고 라벨에 표기.

## 4. 어르신 키오스크 (리스킨, `/kiosk`)

기존 구조 유지 + 블루/화이트 + EV 게이지 차용. 접근성(큰 글씨·큰 터치·AAA 명암) 유지.

- **상단**: 시계·날짜 + `연결됨`(good) 칩
- **상태 히어로**: 큰 `RadialGauge`(블루) + 가운데 shield-check + "지켜보고 있어요 / 실내 모드 · 카메라 꺼짐". 실외 모드 시 게이지·아이콘·문구 전환(amber walking).
- **4 타일**: 건강 상태(`72 회/분` + 스켈레톤 로딩) · 보행 도움 · 가족 연결 · 도움 요청(danger)
- **낙상 오버레이**: 기존 유지(딤 + 빨강 카드 + triangle-alert + "낙상 감지"), 자동 해제 유지
- **전환**: 모드 변경 Framer Motion 크로스페이드, presence pulse는 게이지 링으로 대체/통합

**접근성 앵커 유지**: `data-testid="mode"`(실내/실외 텍스트), 낙상 `role="alert"` "낙상 감지".

## 5. 라우팅 & 구조

```
web/src/
  theme.css              # 블루/화이트 토큰 (신규 단일 진실원)
  components/
    RadialGauge.tsx      # 공통 원형 게이지
    StatCard.tsx  Sparkbars.tsx  IconChip.tsx
    Skeleton.tsx  ActionTile.tsx   # (키오스크, 기존 유지·리스킨)
  views/
    Kiosk.tsx            # 리스킨
    dashboard/
      Dashboard.tsx      # 보호자 홈(신규)
      HeroStatus.tsx  MetricCards.tsx  HomeMap.tsx  ActivityFeed.tsx  TabBar.tsx
  App.tsx                # React Router: /kiosk, /dashboard
```
- `react-router-dom` 추가. `/` → `/kiosk` 기본, `/dashboard` 보호자.
- 안심 상태·활동 파생 로직은 순수 함수(`lib/derive.ts`)로 분리해 테스트 가능하게.

## 6. 스코프 & 구현 순서 (decomposition)

두 덩어리 — 각각 별도 구현계획으로 나눌 수 있음:

1. **디자인 시스템 + 키오스크 리스킨** — `theme.css`, `RadialGauge` 등 공통 컴포넌트, 키오스크 블루/화이트 전환. (기존 테스트 앵커 유지)
2. **보호자 대시보드 신규** — 라우팅, 홈 히어로/카드/지도/소식/탭, 파생 로직.

**권장 순서**: 1 → 2 (공통 디자인 시스템·게이지가 2의 기반).

## 7. 리스크 & 검증

| 리스크 | 완화 |
|---|---|
| 블루 vs 노인 접근성 | 키오스크 본문=딥 네이비, 블루는 큰 구조/액센트만, AAA 명암 유지 |
| 대시보드 데이터 부족(활동·수면) | 스켈레톤 단계 시뮬 데이터 + 라벨 표기, 실데이터는 후속 |
| 신규 화면 스코프↑ | 디자인시스템 먼저 확정 후 대시보드, 공통 컴포넌트로 중복 최소화 |

**검증**: 기존 6 테스트(키오스크 앵커·store·ws) 유지 + `RadialGauge`·파생 로직 단위 테스트 + 대시보드 렌더 테스트. 시각 QA는 Playwright 스크린샷.
