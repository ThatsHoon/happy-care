# 백엔드 연동 + 관리자 콘솔 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `dummy_source.py`를 Gazebo(구현계획_04)에서 실제로 흘러오는 데이터로 대체하는 `gazebo_source.py` 브릿지를 만들고, 웹 텔레옵 + 시나리오 트리거가 가능한 관리자 콘솔(`/admin`)을 추가한다. `설계안_가제보시뮬레이션_관리자콘솔.md` §4~10에 해당.

**Architecture:** 백엔드는 순수 판단 로직(`ModeTracker`, `build_person_state`, `build_robot_telemetry` — rclpy 불필요, pytest로 검증)과 rclpy I/O(`GazeboBridge` — ground-truth 구독→EventBus 발행, 텔레옵/시나리오 명령→cmd_vel/actor_cmd 발행)를 분리한다. `rclpy`는 pyproject.toml 의존성이 아니라 시스템 ROS 2가 제공하므로, `gazebo_source.py`는 함수 내부에서 지연 임포트하고 `ImportError` 시 `app.py`가 자동으로 `dummy_source.py`로 폴백한다. 프론트는 기존 `web/` SPA에 `/admin` 라우트를 추가 — 새 앱이 아니다.

**Tech Stack:** FastAPI(WebSocket 2개 채널) · rclpy(지연 임포트) · React + Vite(기존 SPA 확장) · Zustand

## Global Constraints

- `contracts.py`의 기존 `PersonState`/`CareEvent` 필드는 **무변경** — `RobotTelemetry` 1개만 신규 추가
- 도킹 임계값 **0.3m**, 디바운스 **1초** (설계안 §5)
- 텔레옵 데드맨 스위치 **500ms** (마지막 명령 후 이 시간 지나면 자동 정지)
- 낙상류 시나리오 액터 물리 포즈 자동회복 **5초** (프론트의 알럿 자동해제 6초 타이머는 기존 그대로, 백엔드가 건드리지 않음)
- `gazebo_source.py`는 순수 판단로직/rclpy I/O를 파일 안에서 명확히 분리 — 판단로직 함수·클래스는 최상단에 rclpy import가 없어야 pytest가 ROS 2 없이도 통과한다
- 구현계획_04의 최종 리뷰가 남긴 두 가지를 이 플랜 **Task 1**에서 먼저 해소한다: ① ground-truth 발행이 1kHz라 그대로 구독하면 백엔드가 밀림 → 30Hz로 스로틀. ② `lie`/`fall`이 물리적으로(전이시간 동일) 구분 불가 → 커맨드별 전이시간 분리
- 신규 파일은 `backend/happy_care/`, `web/src/views/admin/`에 평탄하게(새 하위 카테고리 디렉터리 금지)
- `sim/` 빌드가 필요한 태스크(Task 1)는 구현계획_04와 동일하게 `~/happy_care_ws/src/happy_care_sim` 심볼릭 링크 + `GAZEBO_MODEL_DATABASE_URI=""` + `local_setup.bash`(`setup.bash` 아님, cobot_ws 자동소싱 문제) + `DISPLAY` 유지 필요 — 이 워크트리는 새로 만들어지므로 심볼릭 링크를 **이 태스크에서 다시 걸어야 한다**(`sim/README.md` 참고)

- [ ] **Step 4: gazebo_source.py — 순수 판단 로직 작성**

`backend/happy_care/gazebo_source.py`:
```python
"""Gazebo 시뮬레이션 연동 — dummy_source.py를 대체하는 rclpy 브릿지.

순수 판단 로직(ModeTracker, build_person_state, build_robot_telemetry,
_yaw_from_quaternion)은 rclpy를 임포트하지 않아 ROS 2 환경 없이도 pytest로
검증 가능하다. I/O(GazeboBridge)만 생성자 안에서 rclpy를 지연 임포트한다 —
ROS 2가 없는 개발 환경에서는 GazeboBridge() 생성 시 ImportError가 나고,
app.py가 이를 잡아 dummy_source.py로 자동 폴백한다.
"""
from __future__ import annotations

import math
import time
from typing import Optional, Tuple

from .contracts import Activity, PersonState, RobotTelemetry, SystemMode

DOCK_THRESHOLD_M = 0.3
DOCK_DEBOUNCE_S = 1.0
TELEOP_DEADMAN_S = 0.5
FALL_RECOVER_S = 5.0


class ModeTracker:
    """도킹거리 디바운스로 SystemMode를 판정한다. I/O 없음."""

    def __init__(self, mode: SystemMode = SystemMode.OUTDOOR) -> None:
        self.mode = mode
        self._pending: Optional[SystemMode] = None
        self._pending_since: Optional[float] = None

    def update(self, ts: float, dock_distance: float) -> Optional[SystemMode]:
        """거리를 반영하고, 모드가 바뀌면 새 모드를 반환한다(안 바뀌면 None)."""
        target = SystemMode.INDOOR if dock_distance < DOCK_THRESHOLD_M else SystemMode.OUTDOOR
        if target == self.mode:
            self._pending = None
            self._pending_since = None
            return None
        if self._pending != target:
            self._pending = target
            self._pending_since = ts
            return None
        if ts - self._pending_since >= DOCK_DEBOUNCE_S:
            self.mode = target
            self._pending = None
            self._pending_since = None
            return target
        return None


def build_person_state(ts: float, position: Tuple[float, float], torso_velocity: float,
                        activity: Activity) -> PersonState:
    return PersonState(ts=ts, present=True, position=position,
                        torso_velocity=torso_velocity, activity=activity)


def build_robot_telemetry(ts: float, pose: Tuple[float, float, float], dock_distance: float,
                           mode: SystemMode, teleop_connected: bool) -> RobotTelemetry:
    return RobotTelemetry(ts=ts, pose=pose, dock_distance=dock_distance,
                           mode=mode, teleop_connected=teleop_connected)


def _yaw_from_quaternion(x: float, y: float, z: float, w: float) -> float:
    """쿼터니언에서 yaw(z축 회전)만 추출 — 로봇은 평면 위를 움직이므로 충분하다."""
    siny_cosp = 2 * (w * z + x * y)
    cosy_cosp = 1 - 2 * (y * y + z * z)
    return math.atan2(siny_cosp, cosy_cosp)
```

```python
    _yaw_from_quaternion, build_person_state, build_robot_telemetry,

def test_mode_tracker_switches_to_indoor_after_debounce():
    tracker = ModeTracker(mode=SystemMode.OUTDOOR)
    assert tracker.update(0.0, DOCK_THRESHOLD_M - 0.01) is None
    assert tracker.mode == SystemMode.OUTDOOR
    assert tracker.update(DOCK_DEBOUNCE_S - 0.01, DOCK_THRESHOLD_M - 0.01) is None
    result = tracker.update(DOCK_DEBOUNCE_S + 0.01, DOCK_THRESHOLD_M - 0.01)
    assert result == SystemMode.INDOOR
    assert tracker.mode == SystemMode.INDOOR


def test_mode_tracker_resets_debounce_on_bounce():
    tracker = ModeTracker(mode=SystemMode.OUTDOOR)
    tracker.update(0.0, DOCK_THRESHOLD_M - 0.01)
    tracker.update(0.5, DOCK_THRESHOLD_M + 0.5)  # 도킹권 이탈 → 대기 취소
    result = tracker.update(0.5 + DOCK_DEBOUNCE_S + 0.01, DOCK_THRESHOLD_M + 0.5)
    assert result is None
    assert tracker.mode == SystemMode.OUTDOOR
```

```python
import asyncio


class GazeboBridge:
    """rclpy I/O 레이어. 생성자에서 rclpy를 지연 임포트하므로, ROS 2 환경이
    없으면 여기서 ImportError가 나고 app.py가 dummy_source로 폴백한다."""

    def __init__(self, bus, loop: asyncio.AbstractEventLoop) -> None:
        import rclpy
        from geometry_msgs.msg import Pose, Twist
        from std_msgs.msg import Float64, String

        self._bus = bus
        self._loop = loop
        self._mode_tracker = ModeTracker()
        self._last_person_pose: Tuple[float, float] = (0.0, 0.0)
        self._last_robot_pose: Tuple[float, float, float] = (0.0, 0.0, 0.0)
        self._last_dock_distance: float = 0.0
        self._current_activity = Activity.WALKING
        self._last_teleop_ts: float = 0.0

        if not rclpy.ok():
            rclpy.init()
        self._node = rclpy.create_node("happy_care_backend_bridge")

        self._Twist = Twist
        self._String = String
        self._cmd_vel_pub = self._node.create_publisher(Twist, "/happy_care/robot/cmd_vel", 10)
        self._actor_cmd_pub = self._node.create_publisher(String, "/happy_care/actor_cmd", 10)

        self._node.create_subscription(Pose, "/happy_care/robot/pose", self._on_robot_pose, 10)
        self._node.create_subscription(Float64, "/happy_care/robot/dock_distance",
                                        self._on_dock_distance, 10)
        self._node.create_subscription(Pose, "/happy_care/person/pose", self._on_person_pose, 10)
        self._node.create_subscription(Float64, "/happy_care/person/torso_speed",
                                        self._on_person_speed, 10)

    def _publish_threadsafe(self, kind: str, model) -> None:
        from .contracts import envelope
        asyncio.run_coroutine_threadsafe(self._bus.publish(envelope(kind, model)), self._loop)

    def _on_robot_pose(self, msg) -> None:
        yaw = _yaw_from_quaternion(msg.orientation.x, msg.orientation.y,
                                    msg.orientation.z, msg.orientation.w)
        self._last_robot_pose = (msg.position.x, msg.position.y, yaw)
        self._publish_telemetry()

    def _on_dock_distance(self, msg) -> None:
        self._last_dock_distance = msg.data
        ts = time.time()
        new_mode = self._mode_tracker.update(ts, msg.data)
        if new_mode is not None:
            from .contracts import CareEvent
            message = "실내 모드 · 카메라 OFF" if new_mode == SystemMode.INDOOR else "실외 모드 · 보행 보조"
            event = CareEvent(ts=ts, type="mode_change", severity="info", mode=new_mode,
                               message=message)
            self._publish_threadsafe("event", event)
        self._publish_telemetry()

    def _on_person_pose(self, msg) -> None:
        self._last_person_pose = (msg.position.x, msg.position.y)

    def _on_person_speed(self, msg) -> None:
        ts = time.time()
        state = build_person_state(ts=ts, position=self._last_person_pose,
                                    torso_velocity=msg.data, activity=self._current_activity)
        self._publish_threadsafe("state", state)

    def _publish_telemetry(self) -> None:
        ts = time.time()
        connected = bool(self._last_teleop_ts) and (ts - self._last_teleop_ts) < TELEOP_DEADMAN_S
        telemetry = build_robot_telemetry(ts=ts, pose=self._last_robot_pose,
                                           dock_distance=self._last_dock_distance,
                                           mode=self._mode_tracker.mode,
                                           teleop_connected=connected)
        self._publish_threadsafe("robot_telemetry", telemetry)

    async def spin(self) -> None:
        import rclpy
        try:
            while rclpy.ok():
                rclpy.spin_once(self._node, timeout_sec=0.05)
                await asyncio.sleep(0.01)
        finally:
            self._node.destroy_node()
```

(`Tuple`은 이미 Step 4에서 임포트됨, `Activity`도 이미 임포트됨 — 파일 상단 import 라인은 그대로 둡니다.)

```python
    def _send_actor_cmd(self, cmd: str) -> None:
        msg = self._String()
        msg.data = cmd
        self._actor_cmd_pub.publish(msg)

    def _schedule_recover(self) -> None:
        if self._recover_handle is not None:
            self._recover_handle.cancel()
        self._recover_handle = self._loop.call_later(FALL_RECOVER_S, self._recover)

    def _recover(self) -> None:
        self._current_activity = Activity.STILL
        self._send_actor_cmd("recover")

    def trigger_scenario(self, scenario: str):
        from .contracts import CareEvent
        ts = time.time()
        if self._follow_task is not None:
            self._follow_task.cancel()
            self._follow_task = None

        if scenario == "outdoor_fall":
            event = CareEvent(ts=ts, type="fall", severity="critical", mode=SystemMode.OUTDOOR,
                               message="낙상 감지(IMU) — 보호자·119 알림")
        elif scenario == "outdoor_follow":
            event = CareEvent(ts=ts, type="mode_change", severity="info", mode=SystemMode.OUTDOOR,
                               message="자율추종 모드 시작")
            self._follow_task = self._loop.create_task(self._run_follow())
        elif scenario == "outdoor_other":
            event = CareEvent(ts=ts, type="mode_change", severity="info", mode=SystemMode.OUTDOOR,
                               message="기타 시나리오")
        elif scenario == "indoor_fall":
            self._current_activity = Activity.FALL
            self._send_actor_cmd("fall")
            self._schedule_recover()
            event = CareEvent(ts=ts, type="fall", severity="critical", mode=SystemMode.INDOOR,
                               message="낙상 감지 — 보호자·119 알림")
        elif scenario == "indoor_normal":
            self._current_activity = Activity.STILL
            self._send_actor_cmd("idle")
            event = CareEvent(ts=ts, type="mode_change", severity="info", mode=SystemMode.INDOOR,
                               message="정상 활동")
        elif scenario == "indoor_prolonged":
            self._current_activity = Activity.LYING
            self._send_actor_cmd("lie")
            event = CareEvent(ts=ts, type="isolation_warning", severity="warning",
                               mode=SystemMode.INDOOR, message="장시간 무동작")
        else:
            raise ValueError(f"unknown scenario: {scenario}")

        self._publish_threadsafe("event", event)
        return event

    async def _run_follow(self) -> None:
        try:
            while True:
                px, py = self._last_person_pose
                rx, ry, ryaw = self._last_robot_pose
                dx, dy = px - rx, py - ry
                distance = math.hypot(dx, dy)
                if distance < 0.3:
                    self.set_velocity(0.0, 0.0)
                else:
                    target_yaw = math.atan2(dy, dx)
                    yaw_error = math.atan2(math.sin(target_yaw - ryaw), math.cos(target_yaw - ryaw))
                    linear = min(0.4, 0.5 * distance)
                    angular = max(-1.0, min(1.0, 1.5 * yaw_error))
                    self.set_velocity(linear, angular)
                await asyncio.sleep(0.2)
        except asyncio.CancelledError:
            self.stop()
            raise
```

```python
import asyncio
from contextlib import asynccontextmanager

from fastapi import FastAPI, HTTPException, WebSocket, WebSocketDisconnect

from .bus import EventBus


def create_app(with_dummy: bool = False, with_gazebo: bool = False,
               interval: float = 1.0) -> FastAPI:
    bus = EventBus()

    @asynccontextmanager
    async def lifespan(app: FastAPI):
        task = None
        bridge = None
        if with_gazebo:
            try:
                from .gazebo_source import GazeboBridge
                bridge = GazeboBridge(bus, asyncio.get_running_loop())
                task = asyncio.create_task(bridge.spin())
            except ImportError:
                bridge = None
        if bridge is None and with_dummy:
            from .dummy_source import run_dummy
            task = asyncio.create_task(run_dummy(bus, interval))
        app.state.bridge = bridge
        yield
        if task:
            task.cancel()

    app = FastAPI(lifespan=lifespan)
    app.state.bus = bus
    app.state.bridge = None

    @app.websocket("/ws")
    async def ws(websocket: WebSocket) -> None:
        await websocket.accept()
        q = bus.subscribe()
        try:
            while True:
                await websocket.send_text(await q.get())
        except WebSocketDisconnect:
            pass
        finally:
            bus.unsubscribe(q)

    @app.websocket("/ws/teleop")
    async def ws_teleop(websocket: WebSocket) -> None:
        await websocket.accept()
        bridge = websocket.app.state.bridge
        try:
            while True:
                data = await websocket.receive_json()
                if bridge is not None:
                    linear = float(data.get("linear", 0.0))
                    angular = float(data.get("angular", 0.0))
                    bridge.set_velocity(linear, angular)
        except WebSocketDisconnect:
            pass
        finally:
            if bridge is not None:
                bridge.stop()

    @app.post("/scenario")
    async def scenario(payload: dict) -> dict:
        bridge = app.state.bridge
        if bridge is None:
            raise HTTPException(status_code=503, detail="시뮬레이션 비활성 (Gazebo 브릿지 없음)")
        name = payload.get("scenario")
        try:
            event = bridge.trigger_scenario(name)
        except ValueError as e:
            raise HTTPException(status_code=400, detail=str(e)) from e
        return {"ok": True, "event": event.model_dump(mode="json")}

    return app


app = create_app(with_gazebo=True, with_dummy=True, interval=1.0)
```

```tsx
import { useCallback, useEffect, useRef, useState } from 'react'
import { Wifi, WifiOff } from 'lucide-react'
import { useStore } from '../../store'
import './admin.css'

const WS_TELEOP_URL = import.meta.env.VITE_WS_TELEOP_URL ?? 'ws://localhost:8000/ws/teleop'
const DIRECTIONS: Array<['up' | 'down' | 'left' | 'right', string]> = [
  ['up', '▲'], ['left', '◀'], ['down', '▼'], ['right', '▶'],
]
const KEY_MAP: Record<string, 'up' | 'down' | 'left' | 'right'> = {
  w: 'up', s: 'down', a: 'left', d: 'right',
}

function useTeleop() {
  const wsRef = useRef<WebSocket | null>(null)
  const activeDirs = useRef<Set<string>>(new Set())
  const [speed, setSpeed] = useState(0.3)

  useEffect(() => {
    const ws = new WebSocket(WS_TELEOP_URL)
    wsRef.current = ws
    return () => ws.close()
  }, [])

  const sendCommand = useCallback((linear: number, angular: number) => {
    if (wsRef.current?.readyState === WebSocket.OPEN) {
      wsRef.current.send(JSON.stringify({ linear, angular }))
    }
  }, [])

  const computeAndSend = useCallback(() => {
    let linear = 0
    let angular = 0
    if (activeDirs.current.has('up')) linear += speed
    if (activeDirs.current.has('down')) linear -= speed
    if (activeDirs.current.has('left')) angular += 1.0
    if (activeDirs.current.has('right')) angular -= 1.0
    sendCommand(linear, angular)
  }, [speed, sendCommand])

  const press = useCallback((dir: string) => {
    activeDirs.current.add(dir)
    computeAndSend()
  }, [computeAndSend])

  const release = useCallback((dir: string) => {
    activeDirs.current.delete(dir)
    computeAndSend()
  }, [computeAndSend])

  useEffect(() => {
    const onKeyDown = (e: KeyboardEvent) => {
      const dir = KEY_MAP[e.key.toLowerCase()]
      if (dir) press(dir)
    }
    const onKeyUp = (e: KeyboardEvent) => {
      const dir = KEY_MAP[e.key.toLowerCase()]
      if (dir) release(dir)
    }
    window.addEventListener('keydown', onKeyDown)
    window.addEventListener('keyup', onKeyUp)
    return () => {
      window.removeEventListener('keydown', onKeyDown)
      window.removeEventListener('keyup', onKeyUp)
    }
  }, [press, release])

  useEffect(() => {
    const id = setInterval(() => {
      if (activeDirs.current.size > 0) computeAndSend()
    }, 100)
    return () => clearInterval(id)
  }, [computeAndSend])

  return { press, release, speed, setSpeed }
}

function TeleopPanel() {
  const { press, release, speed, setSpeed } = useTeleop()
  return (
    <div className="teleop-panel">
      <div className="teleop-pad">
        {DIRECTIONS.map(([dir, label]) => (
          <button
            key={dir}
            type="button"
            className={`teleop-btn dir-${dir}`}
            onPointerDown={() => press(dir)}
            onPointerUp={() => release(dir)}
            onPointerLeave={() => release(dir)}
            aria-label={dir}
          >
            {label}
          </button>
        ))}
      </div>
      <label className="teleop-speed">
        속도 {speed.toFixed(1)} m/s
        <input
          type="range" min={0.1} max={0.8} step={0.1} value={speed}
          onChange={(e) => setSpeed(Number(e.target.value))}
        />
      </label>
    </div>
  )
}
```
